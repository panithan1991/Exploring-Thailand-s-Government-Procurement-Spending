### การวิเคราะห์ภาพรวม

จากข้อมูลการจัดซื้อจัดจ้างภาครัฐในช่วงปีงบประมาณ 2567–2569 พบว่า ในปี 2567 มีจำนวนโครงการประมาณ **5.43 ล้านโครงการ** และวงเงินงบประมาณรวมประมาณ **1.24 ล้านล้านบาท** ขณะที่ปี 2568 จำนวนโครงการลดลงเหลือประมาณ **4.66 ล้านโครงการ** แต่วงเงินงบประมาณรวมกลับเพิ่มขึ้นเป็นประมาณ **1.36 ล้านล้านบาท** ซึ่งเป็นระดับสูงที่สุดในช่วงที่ศึกษา สะท้อนให้เห็นว่า **จำนวนโครงการที่ลดลงไม่ได้หมายความว่าวงเงินรวมจะลดลงตามไปด้วย** และอาจสะท้อนถึงการมีโครงการที่มีขนาดวงเงินสูงขึ้นในภาพรวม สำหรับปี 2569 ข้อมูล ณ ช่วงเวลาที่รวบรวมมีประมาณ **3.94 ล้านโครงการ** และวงเงินงบประมาณรวมประมาณ **1.17 ล้านล้านบาท** โดยราคาที่ตกลงซื้อ/จ้างคิดเป็น **94.91% ของวงเงินงบประมาณ** สูงกว่าสองปีก่อนหน้า อย่างไรก็ตาม การเปรียบเทียบปี 2569 กับปีงบประมาณที่สิ้นสุดแล้วควรพิจารณาด้วยความระมัดระวัง เนื่องจากข้อมูลยังเป็นข้อมูลระหว่างปี

โดยภาพรวม ราคาที่ตกลงซื้อ/จ้างในทั้งสามปีอยู่ที่ประมาณ **94–95% ของวงเงินงบประมาณ** ค่อนข้างสม่ำเสมอ ขณะที่ค่าเฉลี่ยวงเงินต่อโครงการสูงกว่าค่ามัธยฐานอย่างชัดเจน สะท้อนว่าการกระจายของวงเงินโครงการมีลักษณะ **เบ้ขวา (Right-Skewed Distribution)** กล่าวคือ โครงการส่วนใหญ่มีวงเงินไม่สูงมาก แต่มีโครงการขนาดใหญ่จำนวนหนึ่งที่มีวงเงินสูงมากและส่งผลต่อค่าเฉลี่ยและวงเงินรวมอย่างมีนัยสำคัญ
